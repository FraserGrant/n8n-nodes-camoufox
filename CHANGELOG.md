# Changelog

## 0.1.0

- Initial MIT-licensed Camoufox integration for the Camofox REST API.
- Nineteen named actions with readable workflow canvas subtitles, per-item
  parameters, paired outputs and binary PNG screenshots.
- Encrypted API credentials, authenticated connection tests, bounded requests,
  safe errors and explicit missing-tab handling.
- CI installs npm archives into real n8n instances and exercises browser actions
  against a local fixture site. Release publication includes npm provenance.
